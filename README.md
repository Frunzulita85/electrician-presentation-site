# VoltGuard Electric — Platformă Web & Lead Generation pentru Electricieni

O aplicație web modernă, optimizată pentru Vercel și concepută special pentru servicii electrice rezidențiale, intervenții de urgență și optimizare SEO locală (focalizată pe zona Brașov și împrejurimi).

## Despre Proiect

Platforma este structurată pentru a maximiza rata de conversie (apeluri telefonice rapide și cereri de ofertă) și pentru a oferi o prezență digitală de încredere:

- **Flux dublu de conversie:** Opțiune directă de apel de urgență (24/7) și formular structurat pentru oferte de lucrări planificate.
- **Arhitectură SEO Locală:** Pagini dedicate pentru servicii (tablouri electrice, iluminat, PRAM, reablări) și secțiuni configurabile pentru zone/cartiere deservite.
- **Performanță ridicată:** Construiți pe o stivă tehnică de ultimă generație, garantând timpi de încărcare ultra-rapizi pe dispozitive mobile.

## Stiva Tehnică (Tech Stack)

- **Framework:** Next.js 16 (App Router)
- **UI & Library:** React 19, TypeScript
- **Styling:** Tailwind CSS 4, Lucide React (Icons)
- **Deployment:** Vercel-ready

## Pagini Incluse

- **Acasă (`/`)** — Prezentare generală, intervenții rapide, puncte forte și recenzii.
- **Servicii (`/services`)** — Listă detaliată a serviciilor electrice oferite.
- **Ofertă (`/quote`)** — Formular rapid de cerere de ofertă și contact.

## Instalare și Rulare Locală
